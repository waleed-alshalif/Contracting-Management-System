# Contracting Management System 🏢

Welcome to the **Contracting Management System** project! This is a desktop application designed to streamline the management of contracting operations, including employees, contractors, and ongoing projects.

## 📝 Description

The Contracting Management System is a comprehensive Windows-based desktop application developed to facilitate the daily operations of a contracting or construction business. The system provides secure role-based access for both administrators and regular users, ensuring data integrity and privacy. It features intuitive modules to manage contractors, workforce data, employees, and project tracking. The user interface is designed to be modern and user-friendly, offering an efficient workflow for managing complex business data.

## 🛠️ Tools, Technologies, & Languages

This project was built using the following stack:

- **Programming Language**: C# (C-Sharp)
- **Framework**: .NET Framework 4.7.2
- **Application Type**: Windows Forms (WinForms) for Desktop
- **Database**: MySQL (using `MySql.Data` and `MySqlConnector` for data operations, and `MySqlBackup.NET` for database backup functionality).
- **UI Framework**: Guna.UI2.WinForms - Used to design a modern, sleek, and attractive user interface with custom controls that go beyond standard WinForms controls.
- **IDE**: Microsoft Visual Studio

## 🚀 Key Features

- **Role-Based Authentication**: Secure login and sign-in functionality separated for Administrators and Users.
- **Password Recovery**: Integrated password reset capabilities.
- **Contractor Management**: Add, update, and manage contractor details effortlessly.
- **Employee & Workforce Tracking**: Dedicated modules to manage the workforce and company employees.
- **Project Management**: Organize and track contracting projects.
- **Database Backup**: Built-in functionality to backup the MySQL database to prevent data loss.
